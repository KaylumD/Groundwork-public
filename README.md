# Groundwork-public

Public support and privacy pages for the Groundwork app, served by GitHub Pages.

- `index.html`: home, with the marker download
- `support/`: getting started, common problems, contact (the App Store support URL)
- `privacy/`: privacy policy (the App Store privacy policy URL)
- `marker/groundwork-marker-A4.pdf`: the printable table marker, copied from the app repo's `marker/` folder

Plain HTML and one stylesheet, no build step. The logo and marker come from the app repo's `brand/` and `marker/` folders: copy them across again if they change there.

Before App Store submission: add the support email to the Contact sections of `support/index.html` and `privacy/index.html` (marked TODO).
